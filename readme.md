# Eon Episode Laravel System

A custom Laravel-based web application developed for **Eon Episode Weddings**, combining a public photography and cinematography website with a custom administrative dashboard and password-protected client proofing galleries.

The system was developed to manage website content, customer enquiries, media, and private client galleries through a centralized backend.

## Live Website

https://www.eonepisode.com/

## Project Overview

Eon Episode Laravel System is a real-world web application developed for the day-to-day operations of Eon Episode Weddings.

The application consists of two main components:

- A public-facing photography and cinematography website
- A custom administrative backend for managing website content and client services

The administration system allows website content to be updated without manually modifying individual website pages.

## Key Features

### Custom Admin Dashboard

A centralized administrative dashboard provides access to the major content and client-management functions of the website.

### Homepage Slider Management

Administrators can manage the homepage slider, including:

- Large and small titles
- Slider images
- Read-more links
- Text colour settings
- Mobile image positioning

### Photography Gallery Management

The backend provides database-driven gallery management with the ability to:

- Manage photography gallery content
- Assign couple names
- Assign event types
- Select images to feature on the homepage
- Maintain gallery image records
- Remove deleted image records from the database

### Password-Protected Client Proofing Galleries

The application includes a private proofing gallery system for photography clients.

Administrators can create individual client accounts and provide controlled access to private galleries.

Features include:

- Individual client accounts
- Password-protected access
- Separate client gallery folders
- Client account management
- Private photography proofing

### Cinematography Management

The backend provides tools for managing the cinematography portfolio, including:

- Video titles
- Couple names
- Video categories
- YouTube video links
- Video thumbnails

### Homepage Video Management

Homepage video content and its preview image can be managed through the administration panel.

### Testimonial Management

Administrators can add and update client testimonials, including:

- Client names
- Testimonial text
- Dates
- Images

### Online Quotation Requests

Visitors can submit quotation requests through the public website.

Submitted enquiries are stored and made available through the administration dashboard for review and follow-up.

### Instagram Integration

The application includes support for managing the website's Instagram integration through the administrative backend.

## Project Structure

The repository follows a Laravel application structure:

    app/
    bootstrap/
    config/
    database/
    public/
    resources/
    storage/
    tests/
    artisan
    composer.json
    composer.lock

The production application uses a split hosting configuration where the Laravel application core and publicly accessible files are separated.

For this repository, the project has been organized into a standard Laravel-style structure for development and portfolio presentation.

## Security

Sensitive production information is intentionally excluded from this repository.

The repository does not include:

- Production `.env` configuration
- Database passwords
- API credentials
- Access tokens
- Mail credentials
- Private client data
- Production database dumps

Environment-specific credentials and configuration are kept outside version control.
